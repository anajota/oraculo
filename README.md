# Oráculo

Projeto web desenvolvido com Python e Django.

## Sobre o projeto

O Oráculo é uma aplicação Django criada para praticar desenvolvimento backend com Python, estruturação de projetos web, rotas, views, templates HTML e arquivos estáticos.

## Tecnologias utilizadas

- Python
- Django
- HTML
- CSS
- SQLite
